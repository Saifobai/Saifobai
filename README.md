# About Me

I enjoy building end-to-end systems that combine software, AI, and hardware when the problem calls for it.

- 🚀 Building full-stack applications with **MERN, Next.js, and FastAPI**
- 🤖 Working with **AI agents, LLMs, RAG pipelines, and automation**
- 🔌 Exploring **Arduino, IoT, and hardware-software integration**
- 🏢 Interested in **real estate technology, business automation, and scalable systems**
- 📍 Based in **Hannover, Germany**
- 💬 Ask me about **React, Node.js, LangChain, FastAPI, or AI integration**
